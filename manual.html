Manual

Using Patina Plot

Patina Plot makes scientific graphs and fits curves to data. This page covers what you need to start: installing, plotting, fitting, getting graphs into Word, and letting an AI assistant plot for you.

Install

  1. Download PatinaPlot-Setup.exe from the download section.
  2. Run it and accept the licence. Patina Plot installs for your user account only, to %LOCALAPPDATA%\Programs\Patina Plot, without administrator rights.
  3. Start Patina Plot from the Start menu, or double-click any .ptn project.

Windows may warn that the program is from an unknown publisher, because it is not code-signed. Choose More info, then Run anyway.

macOS (coming soon)

When the Mac build is out, unzip patina-plot-macos.zip and move Patina Plot.app to Applications. The first time, right-click it and choose Open, because the app is not notarized yet. One app runs on both Apple silicon and Intel Macs, macOS 11 or later.

Portable

The .zip for Windows holds the same programs: unzip it anywhere and run patina-plot.exe. Settings and saved templates live in %APPDATA%\Patina Plot either way.

Your first graph

  1. On the Start page choose Blank project, or Import data for a .csv, .tsv, .txt or .dat file, or Paste a table after copying cells in Excel.
  2. Type into the worksheet: Enter moves down, Tab moves right. A first row that is not a number becomes the column's long name. Right-click a column header to set its role (X, Y, Y error) and units.
  3. Select the Y columns and choose a plot type on the Plot tab, or Plot Setup to pick columns for many curves at once.
  4. Click any part of the graph to edit it in the Inspector: an axis, a title, a curve, the legend. Double-click a title to type it where it is drawn.
  5. Ctrl+S saves the project as a .ptn file. It appears on the Start page with a thumbnail next time.

Pick the page size on the graph toolbar: 85, 120 or 175 mm wide for journal single, 1.5 and double columns, 240 mm for slides, or your own size. Fonts follow the preset.

Fitting a curve

Select the data and choose Fitting > Nonlinear. Type a formula such as y = y0 + A*exp(-x/t), or pick a function from the library: exponential decay, growth and rise (ExpDec1, ExpGro1, ExpAssoc…), logarithm, peaks, sigmoids, power laws and soil water retention, plus any .FDF files on your computer. Save to my functions keeps a formula you typed for every project. Starting values are guessed from the data; set any parameter to fixed if you know it.

  • The fitted curve and the residuals go into new columns, and the curve onto the graph.
  • Parameters with standard errors and R² appear in the Inspector, ready to copy into Word or Excel as a table (Copy Table). Add to Graph writes the equation onto the graph.
  • Several datasets at once: fit each on its own, concatenate them, or fit them globally with shared parameters. A report sheet keeps one row per dataset.
  • Fitting > Linear and Polynomial fit straight lines and polynomials up to order 5.

Plot groups and templates

Plots in a layer form a group that steps through colours, symbols and line styles. Open Plot group from a plot's Group tab to choose subgroups (every N plots, or by a column label such as a temperature) and what changes per subgroup or within it. A layer can hold several groups; the Objects tab beside the Inspector shows them as a tree where you can hide, reorder and regroup plots.

Templates… on the Graph tab saves a graph's look without its data. A new graph from the template on the Start page, or Plot Setup with a template, styles new data the same way.

AI plotting (MCP)

patina-mcp.exe is a Model Context Protocol server. Every Patina command is a tool, so an assistant can fill worksheets, fit, plot and style graphs as the menus can. With the Patina Plot window open it works in the window while you watch; without one it works in the background and saves or exports files. The Start page shows the configuration for your computer, ready to copy.

Claude Code

claude mcp add patina-plot -- "%LOCALAPPDATA%\Programs\Patina Plot\patina-mcp.exe" --gui

Use the folder you unzipped Patina Plot into if it is not the one above. On a Mac:

claude mcp add patina-plot -- "/Applications/Patina Plot.app/Contents/MacOS/patina-mcp" --gui

Claude Desktop

Add this to %APPDATA%\Claude\claude_desktop_config.json, with your own user name, then restart Claude Desktop:

{
  "mcpServers": {
    "patina-plot": {
      "command": "C:\\Users\\<you>\\AppData\\Local\\Programs\\Patina Plot\\patina-mcp.exe",
      "args": ["--gui"]
    }
  }
}

Other MCP clients

Any client that runs a stdio MCP server works: point it at patina-mcp.exe.

CommandBehaviour
patina-mcpWork in the open Patina Plot window; if none is open, work in the background.
patina-mcp --guiAlways work in the window, which may be opened later.
patina-mcp --headlessNever touch a window: work in memory, save projects and export graphs.
--port <n>The window's control port (7979 unless the window was started with --control <n>).

What to ask for

Describe the graph as you would to a colleague, and say where it goes:

“Import flow.csv, plot discharge against time with error bars, fit a Gaussian and copy the graph for Word.”

“Plot Book2 with the template Triaxial, one colour per confining pressure, and export it as a 600 dpi PNG for a single column.”

The assistant renders the graph to check its own work. Every step shows in the Activity panel at the bottom of the window, and Ctrl+Z undoes any of it.

Troubleshooting

  • Windows blocks the program: right-click the zip, choose Properties, tick Unblock, then unzip again; or use More info > Run anyway.
  • The assistant cannot reach the window: the status bar shows MCP 127.0.0.1:7979 when the window listens. Another program on that port stops it; start Patina Plot with --control 7980 and give the server --port 7980.
  • The graph looks blurry in Word: use Copy for Word rather than a screenshot, so Word receives the vector EMF.
  • Thai text shows as boxes: install the Sarabun font, or any Thai font; Patina falls back to Leelawadee UI on Windows.
